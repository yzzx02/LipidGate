# 高置信度拟合、固定曲线回捞

后续增加了实际 RT 重选、系列顺序约束与稀疏支持，最新结果见 [ECN 同系物顺序约束](ecn_ordered_20260914.md)。本文保留首版方法和计数。

## 输入与方法

使用 2026-09-13 完整重跑的 32,105 条候选：补测替换规则已经生效，但从旧 RT/ECN 筛选前开始，未只使用上一版通过筛选的记录。无需再次读取 mzML 或重新匹配谱库。

按模式、类别、总双键数独立建模，在同一 DB 系列内拟合归一化 RT 与总碳数的关系，沿用现有 ECN 同系物模型。训练只用原鉴定为高置信度的 Top1；同一碳数只取一个代表锚点，优先分数、同分时取 RT 中位数附近的完整记录。高置信度的定义取自 MS2 门控与 MS1 支持，不由本次 RT 拟合赋予。

仅训练集执行原有线性／二次曲线拟合与稳健离群点处理。有效曲线最终至少保留 4 个不同碳数的高置信度锚点。低置信度和其他候选在曲线固定后统一评估，绝不加入拟合、替换锚点或延长拟合范围。

通过标准为：位于有效拟合碳数范围内，实测归一化 RT 与预测值的绝对差不超过 0.5 min。高置信度记录同样需要通过此标准才能进入最终结果。低置信度记录通过后仍保留低置信度；没有 MS1 支持时使用其 MS2 归一化时间，MS1 峰顶仍为空。

无法建模和超出拟合范围属于未判定，不代表 MS2 鉴定错误，单列保存。未使用原先“存疑但仍保留”或“缺曲线直接保留”的宽松最终输出逻辑。

## 计数修复

核对图表时发现原链解析器将括号中的附加酰基当成命名后缀，可能漏算其 C/DB，例如 ASM d34:2(O-18:0) 原计为 34:2，应为 52:2。

`names.py` 现在保留原命名结构，但总组成独立统计链部分中全部显式 C:DB 核心。覆盖 ASM、酯化 Cer、AHexCer 等嵌套链，同时测试普通氧化链后缀不被重复计数。本批实际纠正 153 条 ASM 候选。之后重新完成了拟合和导出。

## 结果

| 项目 | 数量 |
| --- | ---: |
| 输入候选 | 32,105 |

| 有效曲线 | 187 |
| 实际高置信度训练锚点 | 1,273 |

最终按类别、名称汇总，优先高置信度，再按候选排名和分数选择同一完整证据。2,247 条回捞证据可同时支持已有高置信度名称，不能理解为新增加 2,247 个独立脂质。

OxPE 各 DB 系列仅有 0–3 个不同碳数的高置信度 Top1 锚点，未生成有效曲线；包括先前 90.86 分的示例在内，相关候选归入 RT 未判定，并非撤销其原 MS2 置信度。总览专门展示其高置信度散点而不虚构曲线。

## 验证

全套 562 tests、3118 subtests 通过，17 项既有第三方警告。新增回归覆盖：低置信度极端点不改变曲线、MS2-only 可按固定曲线回捞但不升置信度、模式隔离、Top2 不参与训练、稀疏系列与外推不进入最终结果，以及嵌套链总组成。

额外核对实际输出：全部训练点均为高置信度 Top1，回捞证据均保持低置信度，所有最终通过记录的 RT 残差均在 0.5 min 内。
