# 结果浏览工作台第一版（2026-09-21）

按用户提供的 `LipidGate_result_view_redesign_spec.md` 实现。改动前已创建 Git 检查点 **be2531b**，包含此前稳定库、算法、项目流程和 MS1 页面布局；工作分支为 `codex/results-workbench`。

## 页面职责

- **5 过滤与导出**：Top N、分数过滤、ECN 开关/RT 容差、阈值带、DPI、Excel 导出选项及启动按钮。CSV 和审计继续自动生成。没有增加新的置信度分数阈值：高低置信度仍由现有 MS1 支持/碎片证据逻辑决定。
- **结果查看**：三栏工作台，包含统计、搜索、浏览筛选、交互式 RT–m/z 图、分页结果表、候选切换、注释/碎片证据、理论位置和实验 MS/MS、筛选结果导出及已生成的 ECN 图像入口。此页不运行评分或 ECN 拟合。
- 分析完成后自动进入结果查看。项目重新打开时读取最近一次 Excel 或 CSV 结果。

## 第一版已实现

- 显示全部/已鉴定/未鉴定的单选、置信度多选、ECN 多选及脂质大类/亚类树。组内 OR，组间 AND；类别父节点整组选取并显示部分选中状态。
- 搜索 Annotation、Feature ID、m/z 和 RT；类别树另有搜索。
- 导航图颜色只表示脂质类别。默认淡化未选结果，可改为隐藏；支持 hover、单击选中外圈、缩放、平移、区域框选及恢复视图。
- 导航图与表格双向定位。表格全结果排序、分页及 50/100/250/500 行设置；切换窗口大小后保持选中行可见。
- 特征使用“来源文件 + 实际 Feature ID”区分，没有 Feature ID 时使用文件和 scan。一个特征有多张 MS2 时，浏览代表谱图的候选；不把不同文件或不同 scan 的候选拼成同一张实验谱。
- 默认候选按原始 Rank、Score 顺序展示；切换候选刷新注释、证据与理论碎片，固定特征 RT、前体质量及实验谱。
- 理论棒线等高，未赋予虚假的理论相对强度；实验图显示参与匹配的真实峰强度。四类碎片颜色与方案一致，hover 显示观测/理论质量、ppm、碎片名和类别。
- 已有碎片证据逐条显示，不再重复增加“链门控通过”等结论。
- 当前筛选可导出为“浏览结果”和“候选证据”两个白底工作表。原始分析输出不被覆盖；最终鉴定导出的原有 17 列投影保持不变。

统计中的“可用特征”指当前导入的可浏览特征/谱图条目，不是最终去重名称数。若有项目原始 MS1 特征表，会纳入真实未鉴定特征；只有鉴定表时不凭空补出未鉴定特征。没有置信度记录的旧行显示“未提供”，明确筛选高或低时不会混入。全部勾选时可浏览未鉴定及缺失状态。

打开项目的最终结果文件会优先使用其相邻 `audit/evaluated.csv`，因此能够浏览被分析过滤排除的候选。界面会说明这一点，避免与最终名称去重表的数量混淆。

## 数据接口与兼容性

新增候选审计字段 `ms2_evidence_json`，只序列化已完成评分的 CandidateScore 匹配和实验峰。字段不进入 17 列最终 Excel。碎片角色复用现有类别/链证据判定；普通辅助丢失归 Other，不因名字含脂肪酸就自动标成链门控。

旧 CSV/Excel 未保存完整理论碎片和实验峰强度时，仍可浏览记录、筛选、候选和已报告的碎片文字；谱图区明确提示缺少快照。**不会将旧表中的命中 m/z 伪装成完整实验谱，或给它们填入猜测强度。**新运行结果具备完整浏览快照。没有保存 ECN 状态的旧展示表标为无法判断。

`identification_confidence`、`annotation_level_label`、`prepare_ms2_result_export_df` 从搜索模块移到轻量模块，原导入路径继续兼容。通过 AST 比对确认三个函数内容未改变；`score_spectrum` 除序列化快照外与检查点一致。库、评分公式、排名和 ECN 模型没有重设计。

Windows 上实际验证发现 Qt GUI 与 pyOpenMS 自带 Qt DLL 在同进程可能冲突。GUI 改为在隐藏的独立 Python 后台进程调用原 `run_project`，通过进度和结果路径消息返回；浏览和导出模块不再加载原生质谱引擎。没有更换分析算法。
