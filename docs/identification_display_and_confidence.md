# 关联、积分与置信度

| 信息 | 含义 |
| --- | --- |
| MS1 feature | 检测峰关联；主行描述跨样本特征，逐谱详情描述本样本 |
| MS1 evidence | 原始 MS1 扫描是否在质量和时间要求内确认前体 |
| Confidence | 当前候选的 MS1 证据、必需 MS2 门控和结构覆盖 |

`Confirmed precursor` 不保证存在检测峰 ID、面积或可靠边界。原始 EIC
有信号的峰可能未通过检测器的峰高、信噪比或峰宽设置。检测峰存在
却未关联时需查看质量误差、原始峰顶时间、边界和关联原因。

High 要求分数达到置信度门槛（50）、MS1 证据成立、规定 MS2 门控通过，
且结构不是暂定或不足的单链覆盖。缺头基救援、暂定结构、无 MS1
证据或未评估 MS1 仍是 Low。高分不会覆盖这些限制；此处的置信度
独立于分数，也不是 MSI level 1 或标准品验证等级。

## 同峰归组

本样本未检出或未确认前体，不阻止 MS2 归入跨样本同峰特征。成员
关系依据前体质量、原始 EIC 实测峰顶和局部峰身份。默认峰顶归组
容差为 0.1 min；同文件有谷底分隔的邻峰即使更接近也保留。峰前 / 后
MS2 的采集时间不会代替实际峰顶。

归入已有对齐特征必须唯一；不会生成本样本原生 Feature ID、面积
或边界。每张谱保留自己的候选、门控、分数和置信度；同一峰内 High
与 Low 谱可并存。不同鉴定名称可以分别输出。

已有本样本检测峰、但 MS2 采集在积分区间外时，可按原始 EIC 实测峰顶
重新关联：须由原生峰顶约束过的 EIC 分界提供局部峰身份，同文件、
质量容差内且实测峰顶完全一致的检测特征只能有一个。缺少该证据、
多解或边界未确认时不恢复本地关联。恢复不扩展积分范围，不修改
面积、MS2 时间、候选顺序或分数，原始拒绝原因另存审计。
EIC 复核读取原生检测区间及其同质量相邻检测峰的完整上下文，避免
短窗口从邻峰中段开始，误将已有检测峰判成被截断的曲线。此读取
范围不是新的积分范围；缺少该时间附近检测特征时不会借用远处同质量峰。
`Unlinked` 表示未关联检测特征，并不表示已检出色谱峰；非零原始强度
也不能替代峰检测。界面不再据非零强度显示“有 MS1 信号”。

主鉴定按合格 Top1 的支持样本数选择，每个样本最多一次；同一样本有明确的
高置信分歧或 Top1 并列时不强行投票。FA、NAE 保持独立。同名结果只展示一份
最佳完整记录，其他高置信不同结果保留为差异提示。支持比例不等于鉴定置信度。
CSV、Excel 和浏览器主表均为每个特征一行、一组实测面积，其他候选另表保存；
普通浏览按需读取逐谱详情，完整分数、gate 和置信度仍在磁盘审计中，详见
[特征级汇总](feature_top3_results.md)。

## 边界和积分

pyOpenMS 峰依据各样本原始 EIC 谷底和峰脚修正边界，保护同质量邻峰，
以实际扫描时间对未平滑强度积分。分界不可靠时保留原值并记录待
复核状态。对齐不会借用其他样本边界。没有本样本可靠边界时不显示
EIC 面积填充。

半高全宽只作为 pyOpenMS 检峰参数。边界后处理不计算半高宽、不用
半高宽作第二次筛选，也不覆盖检测器输出的 FWHM、特征 ID、m/z 或 RT。
边界后处理的取窗和通过判定也不读取峰宽参数或检测器宽度统计值；
取窗依据检测器给出的实际边界，并在原始 EIC 中寻找谷底或基线。
没有实测边界的旧表或原生特征不再用 RT ± FWHM/2 补造边界。
平滑曲线仅帮助定位峰顶与谷底，最终边界落在实测扫描上：相邻峰之间
用谷底分开，若已先回到基线则在基线附近收边。即使谷底高于小峰的
半高，也不会因此拒绝该局部峰的边界证据。

若两个检测器峰顶仍处在同一个积分区间，且不能找到可靠谷底，保留
检测器结果并记录 `neighboring_detector_apex_not_separated`，不把它们
作为边界已确认的积分。表中保留原面积、原边界、边界版本、确认状态
以及左右端点属于谷底还是基线；重复修正保留首次记录的原始值。
边界版本 8 优先采用检测器原始区间与峰顶，仅在其附近读取少量额外扫描，
必要时包含已知同质量邻峰峰顶。界面的 RT ±1 min 是显示窗口，不参与
确定积分边界。合理的原生端点保留；跨邻峰的边界移到实测谷底，明显
过窄的端点从原端点向外延伸，过宽且包含长段低强度背景时才收窄。
不会因为局部背景估计偏高就把已有特征缩成尖顶。主面积为未扣基线的
原始 EIC 梯形积分；扣基线面积另存审计字段。

原有谷底／峰脚修整先完整执行；其结果不超过 120 秒时不执行新增背景修正。
只有修整后仍超过 120 秒的异常宽区间，才复核其中的持续背景。120 秒
是独立的异常复核触发值，不是 FWHM、不筛除检测峰，也不是积分时长硬上限。
背景证据不足时仍保留原算法结果；不会为关联更多 MS2 而扩展积分边界。
对这些异常区间，左右侧分别估计稳健的缓慢线性背景，
排除前景峰对背景拟合的拉高影响。孤立零值不强迫背景归零；背景必须
在原生端点仍有非零支持，不能用一条下降到零的拟合线冒充真实拖尾。
只有在五张相邻实测扫描持续回到背景、被移除的背景段明显长于保留峰侧，
且背景幅度与噪声估计可靠时才收窄。过弱或过短的证据保留原边界；
已有邻峰的实测谷底仍是硬分界，不能跨过去。修正原因记录为
`detector_interval_background_repaired`，原始检测面积与端点单独保留。

FWHM 上限限制半高全宽，不是完整轨迹或积分区间的时长上限。后处理
不读取 FWHM 参数、不重新计算 FWHM，也不把完整积分范围硬截为该时长。
参数定义见 [OpenMS ElutionPeakDetection](https://openms.de/documentation/classOpenMS_1_1ElutionPeakDetection.html)。

原生宽峰内部只有在两个峰脊均有连续扫描支持、谷底持续超过单个扫描、
谷底不高于较小峰扣背景高度的65%、谷深至少5倍局部噪声，且较小峰
至少达到该区间最强峰的20%时，才提出局部分峰。提议本身不生成 ID。
实际局部 OpenMS 检测采用原检测参数，只有真实检出才新增原生特征，
并保存 `split_parent_native_uid`、`detector_origin` 与触发来源。
DDA 文件只对有原始 MS2 前体事件的漏分子峰启动局部重检，不使用库名
或得分；MS1-only 文件不加此请求限制。重检仅读取该谷底区间、目标
质量附近及真实相邻质心点，避免反复读取或重新检测整个文件。
积分端点可以是非零谷底，不强制归零。局部重检失败时既不编造特征，
也不使用未确认的分峰建议裁断父峰；只有真实邻峰才提供强制谷底分界。

局部回溯边界的思路参考
[MS-DIAL 方法论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4449330/)及
[MS-DIAL 峰检测实现](https://github.com/systemsomicslab/MsdialWorkbench/blob/master/src/Common/CommonStandard/Algorithm/PeakPick/PeakPick.cs)。
边界修正是本项目实现；新增分峰由 OpenMS 实际局部重检产生，不复刻
MS-DIAL 的完整检测器。

主行分别报告 MS1 检出样本数、MS2 样本数和谱图数；MS2 样本更多
并不意味着所有样本都有检测器积分面积。
