# Release contents

Public source includes production code, tests, generic library maintenance and
build tools, documentation, fonts/icons, compressed MSPs and release hashes.
Windows packages contain the executable, usage, manifest, checksums and notices.
The provided Source ZIP includes actual Git LFS library payloads; automatic
GitHub source archives may contain pointers instead.

Raw samples, experiment outputs/scripts, retired model code/weights, editor
state, build caches and old executables are outside current source and assets.
Reproducibility materials are locally archived outside the project.

Git history is retained. Removing a file from the current tree does not remove
it from older commits; each published tag identifies the exact released tree.
