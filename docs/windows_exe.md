# Windows 桌面版

在 Windows 上双击 `dist/LipidGate.exe` 即可启动。程序包含 Python、PySide6、pyOpenMS、Inter 字体和正负离子 MSP 谱库。首次启动会将依赖解压到系统临时目录。正负模式各有预构建的解析谱库快照；首次匹配仍需将它读入内存并建立索引，但不再从原始 MSP 逐条解析。后续运行复用 `%LOCALAPPDATA%\LipidGate\Cache\ms2_libraries` 中按谱库内容命名的缓存，即使 exe 的临时解压目录变化也能命中。分析结果仍保存在用户选择的项目目录中。

## 使用

1. 创建或打开项目，导入 mzML 文件。
2. 选择 MS1、MS2 参数；需要多文件并行匹配时，在 MS2 页选择 1–4 个进程。
3. 点击“保存参数并开始分析”。进度面板会显示阶段、文件计数、已用时间。MS2 谱库准备单独提示；完成第一个 MS2 文件后给出初步剩余时间，完成更多文件后根据实际速度更新；导出阶段继续显示已用时间。

多文件 pyOpenMS 会先对齐 MS1 特征，再把每个文件的原始峰通过 OpenMS 共识特征成员关系关联到对齐 ID。MS2 仍按同文件原始峰关联，随后回填对齐 ID。结果浏览以一个对齐特征为一行；没有成员关系的 MS1 峰另列。MS2-only 扫描按 5 ppm 和 0.08 分钟保守归组，各原始谱图仍可切换查看；这种归组仅是推测性特征，不能代替 MS1 峰形证据。旧分析没有保存成员关系，结果页只对质量与保留时间均唯一匹配的峰进行保守合并；重新分析才能得到精确对应。

分数和 ECN 过滤在参数页设置；ECN 拟合点不足的亚类可选择保留并标为“无法判断”。CSV 审计文件随分析自动保存。需要结果表、Excel 或 ECN 图像时，在“结果查看 → 导出结果与图像”选择范围、格式、DPI 和目标文件夹。修改源码后重新构建 exe，源代码与已生成的 exe 相互独立。

导航图由 Qt 直接绘制，滚轮缩放不再触发 Matplotlib 对数千个点重绘；点击点才会切换选中特征。英文界面字体使用打包的 Inter，中文使用系统字体。谱图的头基、脂肪链、中性丢失、母离子和未匹配峰使用不同颜色。

默认 pyOpenMS 和 MS2 分析可直接运行。选择 XCMS 时仍需单独安装 R、XCMS 及相关 R 包；选择 Asari 时仍需安装相应 Python 环境。自定义 MSP 谱库仍可通过界面选择。每次修改源码后，需重新构建 exe；构建过程不会修改源码或项目数据。

## 重新构建

在已安装项目依赖的 Windows Python 环境中运行：

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm LipidGate.spec
```

构建时脚本会校验谱库快照与当前规则代码、MSP 文件的哈希；有改动时重新生成快照。输出为 `dist/LipidGate.exe`。若发布给其他人，直接复制这个 exe 即可。由于没有代码签名，Windows 可能首次显示未知发布者提示。
