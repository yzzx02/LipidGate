# 一级特征支持与 LNAPE 规则维护

2026-09-06：按用户要求，一级支持以特征检测结果为依据。此前新增的自定义 EIC 判峰模块已删除，相关阈值不再作为额外门控。

普通软件先完成特征检测；MS2 关联复用输入特征表的 m/z、RT 及峰边界。pyOpenMS 通过 MassTraceDetection、ElutionPeakDetection、FeatureFindingMetabo 完成检测。通用提取器与本地二维 runner 共用 detect_feature_map()，不另写色谱峰质量判定算法。

MS1-supported 表示匹配到了一级特征；MS2-only 表示当前没有关联的一级特征。关联到特征并不证明二级谱结构鉴定一定正确。独立的 MS2 检索不重复提取一级特征，没有输入特征表时标记 feature_table_not_supplied，不能把这个状态解释为原始数据必然只有噪声。

特征表是关联依据，先前 EIC 判定产生的状态不会阻止重新关联。显式未匹配的结果保留二级谱、清空一级特征时间，不经尾部救援重新挂到特征，也不参与 ECN 训练或 RT 过滤。保留动作是 ms2_only_not_evaluated。

单文件原生导出本来已有 RTstart/RTend。现保留原始字段并明确添加 RTmin/RTmax、RT_unit、来源文件和原生 FWHM。后处理统一导出分钟，并同步单位标记；重复读取不会重复转换。带来源字段的特征表只能关联同一来源文件。旧表无单位字段时保留原有单位推断兼容行为。

二维归一化发生在实验 runner 完成原始 RT 关联之后，不属于正式软件的特征判定逻辑。

LCE-PE 空链名称规范化和负模式 LNAPE 的 HG/FA 双门控、60/20/20 权重保持不变。

实测 frag3_NEG_40ev_4.mzML：检测参数为 5 ppm、噪声阈值 1000、S/N 参数 5、FWHM 5–60 秒，得到 12,405 个原生特征。142 张有 MS2 鉴定的谱中，121 张关联到一级特征、21 张未关联。目标 scan_2913（原始 RT 21.34933 min）无对应特征，保留为 MS2-only；LNAPE 为 66.40 分。相对上一轮自定义判断，有 25 张恢复特征支持、10 张改为未匹配，净增加 15 张。所有 268 条候选身份、加合物和分数保持一致。

本轮目标文件已端到端复跑；132 文件整批结果未覆盖。原始数据与详细报告见 outputs/lnape_ms1_review_20260905/pyopenms_feature_review/。完整回归：455 passed，3118 subtests passed；已删除的自定义判峰算法测试随实现撤下。
