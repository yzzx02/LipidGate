# 两个真实点直接建模并参与 RT 筛选

使用已有完整二维 10／10 ppm 鉴定的 32,774 条候选，仅重跑 ECN，不重新搜索 mzML。此前只改变两点展示连线，却未改变借用系数的筛选模型，导致 TG DB11 的 C58、C60 明明位于 DB10 下方，仍因禁止递归借用而被标为未判定。本次同步修正正式模型。

## 实现

两条不同碳数的高置信度实际观测决定直线的斜率和截距。两个覆盖其碳数范围的邻近 DB 系列仅用于验证实际点是否处于合理趋势位置（±0.5 min），不替代它们决定系数。还要求直线随碳数递增，并与所有已接受且碳数范围重叠的系列保持 DB 顺序，不交叉。

两点模型的支持类型为 `observed_two_point_DBx_DBy`，实际点标记为训练锚点。通过上述验证的实际两点直线可以验证紧邻下一 DB 的两点系列，迭代至不再有新系列通过。边缘仍仅允许邻接 1 DB；仅由参考曲线推导、没有两点实际拟合的单点模型，不作为递归参考。所有过程只用原高置信度 Rank1–3，不将低置信度回捞记录加入训练。

若较多候选碳数在邻近趋势验证后只剩两个实际点，也用这两个点拟合，再检查斜率和交叉。单点仍仅在该碳数处验证，不伪造独立直线。未更改三点及更多点的独立共识规则，因此原来 FA DB20 四点孤立系列的问题仍需另行复核。

固定上述模型后，所有候选依旧按 ±0.5 min 和支持碳数范围筛选。图上的两点连线与正式两点筛选模型一致，阴影为正式模型 ±0.5 min。保留原始时间和原鉴定置信度，不修改质量值。
