# 使用说明

## 启动和分析

解压 Windows 应用包后双击 `LipidGate.exe`。
默认 pyOpenMS、Python 以及正负模式谱库已内置。首次启动会解压依赖。
中文 Windows 用户名和临时目录可直接使用，无需额外启动脚本。

「新建项目」和「打开项目」是独立入口。新建时在独立项目文件夹保存
一个命名的 `.lipidgate` 文件，例如 `花生油.lipidgate`，再添加 mzML。
每个文件夹保存一个项目；已有项目或分析结果的文件夹不能新建覆盖。
打开时选择已有 `.lipidgate` 文件；旧项目选择 `lipidgate.project.json`
也能打开，保留原文件及结果。文件不存在或损坏时提示错误，不创建新项目。
项目文件记录文件列表及参数，`runs/` 保存历次分析结果；移动或分享时
需保留项目文件与 `runs/` 的相对位置。每个项目使用同一 LC 方法和一种离子模式；
不同目录的同名样本需先重命名。RAW 数据需先转换为 mzML。项目记录
原始文件路径，不复制数据；移动或分享项目时需同时提供原始文件并
更新路径。

设置 MS1 方式。pyOpenMS 峰宽表示半高全宽，XCMS 峰宽表示 centWave
色谱峰宽范围，单位为秒。噪声、最低峰高、信噪比和 XCMS 最小样本数
分别设置。没有 MS1 扫描的文件跳过 MS1 提取，继续 MS2 检索。
单样本正常提取和积分 MS1 特征，不执行跨样本 RT 对齐。最终结果按样本
保留已有的检测峰面积；只有原始前体信号、没有检测峰的记录不补造面积。

MS2 页选择离子模式，自动使用对应内置库。只有自定义 MSP 才需要选
库文件。加合物与脂质类型在「选择…」窗口中搜索和勾选。前体 m/z
范围可只设一端且包含端点；范围外扫描不进入检索。它限制 MS2 检索，
不改变 MS1 检测范围。

质量误差可选 ppm 或 Da。Da 为固定绝对误差：0.01 Da 在 m/z 500
对应 20 ppm，在 m/z 900 约为 11.1 ppm，在 m/z 1000 为 10 ppm。
高 m/z 的 TG 使用 0.01 Da 时，容差会比 20 ppm 更严格。母离子与
碎片的误差分别设置；Da 模式也用于后续特征关联和色谱归组。

保存参数并开始分析。每次运行在项目 `runs/` 下创建独立目录，记录
参数、输入、库身份和候选审计。默认 MS2 进程为 1，多文件可选 1–4；
大文件或内存有限时保持默认。ECN 可选，见 [方法说明](ecn_filter.md)。

## 结果复核

分析完成后自动打开独立结果窗口，参数导航留在主窗口。点击
「返回参数页」可继续设置，结果仍保留。默认布局为散点图分配更多
宽度和高度，四周留白及 MS1/MS2 标签行高收紧；可拖动模块分隔线
调整比例。详情使用正常字号，空间不足时滚动查看，不压缩文字。
关闭结果窗口后可在主窗口点击「结果查看」重新打开。

重新启动后点击「打开项目」，选择该项目的 `.lipidgate` 文件（旧版
为 `lipidgate.project.json`），恢复文件、参数，并自动打开最近一次结果，
无需重新分析。切换到新项目后参数恢复默认，结果窗口不会继续显示旧项目。
有实际 MS1 特征的浏览行显示数字 ID，未关联的 MS2 行保留 `MS2-`
前缀。数字仅用于显示；导出额外保留原始特征 ID，审计关联不变。

pyOpenMS 检峰后的边界修正保留原始 FWHM，不再计算或按半高宽二次
过滤。边界以检测器原始左右端点为起点修整，保留合理的原生边界。
FWHM 上限是半高全宽（秒），不等于完整峰的左右端点跨度。原生区间
先按原有谷底／峰脚算法修整；仅当结果仍超过 120 秒且含长段持续背景时
才追加收窄。120 秒只触发异常复核，正常区间保持原算法结果，不按这个
值或 FWHM 上限硬截积分。
明显双峰只在局部 OpenMS 重检实际检出后增加特征并记录父峰；重检
未确认的分峰建议不会裁断已有原生区间。无法
可靠分开的邻峰保留原结果及原因，详见[边界和积分](identification_display_and_confidence.md#边界和积分)。
重新运行 MS1 提取后采用当前修正规则。

详情中的「MS1 积分范围」为当前代表谱来源样本的实测左右边界；
未能可靠确认时显示「未确认」。旧的「原始峰顶范围」是各样本 MS1
峰顶时间的最小值至最大值，并非 MS2 采集时间，现已替换。
「同位素」按需读取当前代表 MS2 前一张 MS1 的实测峰，与导出定义一致；
不会补造理论峰或据此改动分数和门控。

点击注释特征查看 MS1 EIC 和逐谱 MS2。EIC 默认为 RT ±1 min，缺少
检测峰 ID 的注释也提取原始 MS1 信号。只有本样本实际峰边界存在时
显示积分填充。图内不再显示 RT／±1 min 的副标题。单击或双击 EIC 的
时间点，上方「MS1 全扫描」读取最近一张实际 MS1 扫描，默认定位前体
±3 Da，并在质量容差内将最近的实测前体峰标红；没有实测匹配时不补画
前体线。谱图不画全高度虚线，红色峰线保持原始强度，完整扫描仍保留，
复位按钮恢复全谱。「前体附近」按钮可再次定位。扫描索引与 EIC 共用，峰缓存有
大小上限，原始全谱只在点击时读取，不加载整个文件的峰数组。
MS2 横轴为 m/z，靠近峰线显示碎片信息，移开后隐藏。
「候选注释」显示通过当前输出规则的候选，不一定有三条；分数低于
当前阈值的候选不会为凑满 Top3 而补入。默认选用支持当前注释的一张
最佳实际 MS2，Top3 均来自该谱图。只有样本或扫描的 Top1 不一致时，
才显示不同 Top1 的代表谱切换选项；对应 EIC 使用该谱的来源样本。
结果表与候选表不再显示 Top1 支持、鉴定状态和 ECN 列，完整审计
与导出仍保留原有证据和逐谱决定。

靠近坐标轴右键拖动缩放：右 / 上放大，左 / 下缩小；强度轴固定从
0 开始。导航图内左键可平移。
散点图滚轮围绕鼠标指向的 RT / m/z 同时缩放，不固定 m/z 下边界。
选中特征时，导航图用细灰线连接当前可见且证据明确的加合物峰；
鼠标悬停可查看各峰的 Adduct。结果表只保留 Adduct，不增加联系列。
各加合物峰的注释、得分和面积分别保留，完整联系记录保存在项目中。
EIC 读取失败时可点「错误详情」查看完整原因，或点「重试」。

主行关联状态描述整个跨样本特征；选中谱图的详情描述本样本。
`Not detected` 表示检测峰表中没有对应峰，`Unlinked` 表示未取得有效
检测峰关联，`Confirmed precursor` 表示原始扫描确认前体。高分不
保证 High，置信度还需规定的 MS2 证据。详见
[关联与置信度](identification_display_and_confidence.md)。

导出 CSV / Excel 保存筛选结果；审计表保留完整候选和门控原因。同一
注释的同一峰不会因为某个样本未检出而再开一行；不同鉴定可以分别
保留。MS1 检出样本数、MS2 样本数和关联谱图数可以不同。

导出中的 `MS1 Feature` 为检测峰关联状态，「MS1 前体证据」独立记录
原始扫描是否确认前体。「面积状态」和「MS1 特征说明」解释空面积：
原始 MS1 确认了前体，但没有满足同一样本、质量容差和峰边界的检测
峰时，面积保持为空。未对齐的原始检测峰仍导出本样本实际面积。

「同位素」每个 Feature 只导出一组，采用现有鉴定代表 MS2 在采集
顺序上前一张 MS1，不拼接全部 MS2 的窗口。代表 MS2 按候选排名
优先、得分降序选择，同排名同分保留原顺序，不改变鉴定选择。
格式为 `m/z:相对强度%`，保存前体峰及其后最多三个同位素间隔的实测峰。电荷
优先使用 mzML 记录，否则从候选加合物推断。质量窗口为 15 ppm，
相对强度以导出窗口内最大峰为 100%。起点是实测选中前体，不保证
它是单同位素 M+0；缺失峰不补理论峰，歧义窗口予以省略并标记。
轮廓谱或原始文件不可用时标记原因。特征表附同位素 MS1 的 RT、
来源文件和提取状态；最终 CSV / Excel 不包含扫描号或同位素详情
JSON，逐谱证据不重复同位素。项目原有审计仍保留扫描记录。
MS-DIAL 5 的 LC/MS 导出使用色谱峰顶 MS1 提取同位素，见
[公开源码](https://github.com/systemsomicslab/MsdialWorkbench/blob/master/src/MSDIAL5/MsdialCore/Export/IAnalysisMetadataAccessor.cs#L151)。
LipidGate 当前使用代表 MS2 前的 MS1，二者选谱位置不同。

pyOpenMS、XCMS、Asari 和 MS-DIAL 的完整 MS1 峰表均可重新打开，
包括未鉴定峰和峰表中实际记录的面积。Asari 的原始秒值统一转为分钟。

升级前的项目和结果目录可继续打开。旧版本已经漏做 MS1 提取的运行，
或已经转换错误的 Asari 时间，需要用新版重新分析才能得到修正结果。

## 可选环境和分享

- XCMS：需要 R、XCMS、MSnbase、optparse、BiocParallel，`Rscript`
  在 PATH 中可调用。程序已包含桥接脚本。
- Asari：需要可调用的 Asari / Python 环境，`asari` 在 PATH 中可用。
- MS-DIAL：先导出特征表，再在 MS1 页选择导入。

分享软件只需发送 Windows ZIP，Python 和 MSP 不用另发。分享分析
项目需同时提供原始 mzML。`VERSION.json` 保存指纹，`SHA256SUMS.txt`
用于文件校验。
