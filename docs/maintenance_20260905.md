# PE-Cer 正库新增与项目审查修复

基线：`00ffc21`。本轮修改代码和现行正模式库；历史二维结果保持原样。本次包含有意的科学结果行为修复，不能视作“结果不变”的纯重构。

## PE-Cer [M+H]+

仅采用现有负库非羟基 d-HexCer 的链组合网格，新增 4,914 条非羟基 d 系列 PE-Cer。名称唯一，重复执行建库不会累计记录。未加入 m/t 系列，也未新增 PE-Cer 钠加合物前体条目。

`PE-Cer(d18:1/16:0)` 分子式为 C36H73N2O6P。质量由元素组成计算，带正电的离子扣除电子质量。

| 池 | 碎片名称 | 理论 m/z | 池权重 |
| --- | --- | ---: | ---: |
| HG | M+H-141 | 520.5088 | 60 |
| LCB | LCB-2H2O | 264.2686 | 20 |
| 其他 | [M+H]+ | 661.5279 | 20，共享 |
| 其他 | M+H-141-H2O | 502.4982 | 同上 |
| 其他 | M-141+Na | 542.4908 | 同上 |
| 其他 | FA-amide | 280.2635 | 同上 |

HG 的中性丢失采用 C2H8NO4P 的精确质量 141.0190947 Da。用户原文“−14”按其后续“−141”与经典磷酸乙醇胺丢失解释为“−141”。磷酸乙醇胺丢失和双脱水长链碱产物有原始研究依据：[Masood 等，2010](https://pmc.ncbi.nlm.nih.gov/articles/PMC3020903/)。d18:1/16:0 EPC 的约 661 前体、264/280 链相关产物亦见[2017 年锥虫鞘脂研究](https://www.nature.com/articles/s41598-017-13931-x)。钠相关的可选碎片按用户指定保留在其他池。

FA-amide 是简化名称。16:0 对应 C18H34NO+；其他脂酰链按 C(n+2)H(2n+2−2DB)NO+ 计算，不把 280.2635 硬编码到全部记录。

HG 和 LCB 各要求命中至少一半。两个池各只有一条碎片，因此两条必须同时命中。关闭这类脂质的 HG-only 与 FAH-only 回退。母离子和 FA-amide 等四条仅进入其他池。全峰等强命中为 100 分。

## 已修复内容

1. **注释层级**：导出层只映射评分层给出的等级；不再通过名称正则或完整名称提升等级。SM [M+Na]+ 的中性丢失仅报告分子种类水平。通用鞘脂分支对只有总组成的库名称增加等级上限。PE-Cer 导出保持 LCB 在前。
2. **旧 MS1/MS2 关联**：全部候选未通过门控时保持未注释，不回退到未过滤候选。旧接口仍保留原有分钟制 RT 窗口，避免与秒制接口混淆。
3. **入口一致性**：GUI、CLI、工作流 API、搜索器共用 `SearchConfig`；默认前体 5 ppm、碎片 15 ppm、相对强度 0.002、Top3。GUI 仍允许用户关闭 TopN 或更改参数。通用与二维的 pyOpenMS 路径共用谱图准备接口和 MS1 前体校正；pymzML 回退也调用相同校正核心。极性取自文件，未知时留空。分段起始时间仅由二维调用方传入。通用导出保留原始前体、校正状态与原始 ppm。
4. **检查点**：复用与整合均验证原始文件内容 SHA256、样本/分段身份、参数、谱库内容、有效源代码指纹、结果 CSV 及前体审计文件哈希。代码指纹含未提交的源码变更。整合严格使用 manifest 指定文件，拒绝缺失、旧身份、输出损坏及重复输出身份。部分运行自动跳过整合。缓存存储文件名不再替代原始样本名。
5. **匹配内核**：抽出共用贪心匹配函数；保留理论碎片顺序、等强时取首峰、观测峰仅使用一次。底层旧调用在完全未指定容差时的 0.01 Da / 10 ppm 回退分别保留；产品入口显式使用配置。
6. **读取与化学归一**：提供 `load_standard_msp(normalize=False)` 原始读取接口和独立 `normalize_imported_record` 导入策略。默认运行时兼容策略继续有效。新增按类/加合物抽样的审计工具，未直接删除现有变换。
7. **评分职责**：鞘脂评分从搜索器移到 `sphingolipid_scoring.py`，与普通评分统一返回 `CandidateScore`；搜索器保留兼容方法并负责检索、竞争处理和排序。
8. **导出重复**：共用 Excel 格式与工作簿 writer；权限错误重试只更换目标文件。保留旧三元组 API 和搜索器方法别名，在类定义内声明方法。
9. **建库工具**：MSP 读取、表头、峰解析/重建、校验等集中到 `msp_tools.py`；重复建库工具改为直接导入该模块。新增 PE-Cer 建库器验证唯一性、幂等性及非目标记录内容一致。
10. **缓存与工程项**：库缓存绑定内容哈希和代码指纹；写入使用唯一临时文件与原子替换，失败记录原因。包公共接口改为延迟导入。补齐 GUI 类型引用、移除静态检查发现的未用符号、修复测试的 Python 3.10 语法问题，并忽略本地缓存/工作树/临时目录。
