# 关联、积分与置信度

| 信息 | 含义 |
| --- | --- |
| MS1 feature | 检测峰关联；主行描述跨样本特征，逐谱详情描述本样本 |
| MS1 evidence | 原始 MS1 扫描是否在质量和时间要求内确认前体 |
| Confidence | 当前候选的 MS1 证据、必需 MS2 门控和结构覆盖 |

`Confirmed precursor` 不保证存在检测峰 ID、面积或可靠边界。原始 EIC
有信号的峰可能未通过检测器的峰高、信噪比或峰宽设置。检测峰存在
却未关联时需查看质量误差、原始峰顶时间、边界和关联原因。

High 要求分数达到置信度门槛（50）、MS1 证据成立、规定 MS2 门控通过，
且结构不是暂定或不足的单链覆盖。缺头基救援、暂定结构、无 MS1
证据或未评估 MS1 仍是 Low。高分不会覆盖这些限制；此处的置信度
独立于分数，也不是 MSI level 1 或标准品验证等级。

## 同峰归组

本样本未检出或未确认前体，不阻止 MS2 归入跨样本同峰特征。成员
关系依据前体质量、原始 EIC 实测峰顶和局部峰身份。默认峰顶归组
容差为 0.1 min；同文件有谷底分隔的邻峰即使更接近也保留。峰前 / 后
MS2 的采集时间不会代替实际峰顶。

归入已有对齐特征必须唯一；不会生成本样本原生 Feature ID、面积
或边界。每张谱保留自己的候选、门控、分数和置信度；同一峰内 High
与 Low 谱可并存。不同鉴定名称可以分别输出。

## 边界和积分

pyOpenMS 峰依据各样本原始 EIC 谷底和峰脚修正边界，保护同质量邻峰，
以实际扫描时间对未平滑强度积分。分界不可靠时保留原值并记录待
复核状态。对齐不会借用其他样本边界。没有本样本可靠边界时不显示
EIC 面积填充。

主行分别报告 MS1 检出样本数、MS2 样本数和谱图数；MS2 样本更多
并不意味着所有样本都有检测器积分面积。
